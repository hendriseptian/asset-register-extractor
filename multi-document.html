How consolidation works

  • Each source document is processed independently by the configured Cloudflare Worker.
  • Records are grouped only when their Tag PSV matches. Records without a Tag PSV are not automatically combined.
  • Empty fields can be filled by another matching document.
  • If two documents contain different non-empty values for the same field, the existing value is retained and the difference is flagged for review.
  • Source file names and source locations are retained for traceability.
  • Review the consolidated records before exporting. AI extraction is a draft and requires engineering verification.
